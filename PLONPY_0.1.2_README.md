# PLONPY 0.1.2 — Bloque HUD

Esta versión corrige el HUD para que lea continuamente la misión real del `MissionManager` y evita que quede mostrando un texto antiguo.

## Prueba
1. Abre el proyecto en Godot 4.7.2.
2. Ejecuta con F6/F5.
3. Debe aparecer `M001 — Despertar`.
4. Presiona WASD y comprueba que M001 se completa y entrega 50 XP + 25 CHISPA.
5. Comprueba que aparece M002 — La Llamada.
6. Acércate a la Chispa Primigenia.
7. Comprueba M003 y el progreso 1/3, 2/3, 3/3 al descubrir las tres luces.

G = guardar. L = cargar.
