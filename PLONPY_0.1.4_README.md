# PLONPY 0.1.4

Corrección del error de análisis mostrado en Godot 4.7:
`Cannot infer the type of "nivel_anterior" variable because the value doesn't have a set type.`

También se hicieron explícitas varias variables obtenidas desde nodos dinámicos para evitar nuevos errores de inferencia `Variant`.

## Instalación
1. Cierra Godot.
2. Haz una copia de seguridad del proyecto actual.
3. Reemplaza el contenido del proyecto por esta versión.
4. Abre `project.godot` en Godot 4.7.x.
5. Espera la importación.
6. Ejecuta el proyecto.

No requiere editar scripts manualmente.
