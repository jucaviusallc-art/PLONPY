# PLONPY 0.1.5 — Bloque jugable Costa de Chispa

Esta versión parte de PLONPY 0.1.4 y consolida el primer ciclo jugable.

## Flujo previsto

1. M001 — Despertar: mover al jugador por primera vez.
   - Recompensa: 50 XP + 25 CHISPA.
2. M002 — La Llamada: tocar la Chispa Primigenia.
   - Recompensa: 100 XP + 50 CHISPA.
3. M003 — Tres luces azules: descubrir Eco de Costa, Gota de Luz y Burbuja de Energía.
   - Recompensa: 150 XP + 75 CHISPA.

## Controles

- W A S D: mover
- G: guardar
- L: cargar

## Nota

La versión usa tipado explícito en el Progression Manager para evitar el error de inferencia de Godot 4.7 detectado durante las pruebas.
